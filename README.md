# Banking System in C

## Overview
This is a simple banking system implemented in C that allows users to perform various banking operations such as checking balance, withdrawing and depositing money, transferring funds, changing PINs, and applying for loans. It uses a struct to store account details and a menu-driven approach to navigate through different functionalities.

## Features
- **User Authentication**: Secure login with a password.
- **Account Operations**:
  - Check balance
  - Withdraw money
  - Deposit money
  - Transfer funds
  - View account details
  - Change PIN
- **Loan Services**:
  - Apply for a personal loan (based on CIBIL score)
  - Calculate loan EMIs

## File Structure
- `main.c` - The main source code file containing the banking system logic.

## How to Use
1. Run the program.
2. Enter your password to log in.
3. Choose the desired operation from the menu.
4. Follow the on-screen prompts to complete transactions.

## Example Account Data
The system has predefined accounts with details like account numbers, passwords, and balances. New users are not supported in the current version.
